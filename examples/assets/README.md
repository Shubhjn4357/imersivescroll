# Example assets

Use `pnpm extract "<video-path>"` to turn a local video into the shared example scene.

Example:

```bash
pnpm extract "examples/assets/wildrobot.mp4"
```

The extractor now covers the full video duration while capping the output to roughly `250` frames, auto-selecting fps, downscaling oversized footage to landing-page dimensions, and tuning WebP quality automatically.

The stock sample clip in this folder is generated by `pnpm prepare:example-assets`.
