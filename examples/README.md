# Examples

This directory contains runnable surfaces for validating the packages in real app contexts.

- `next-demo/`: primary site surface with the home page, docs, demo, and playground routes.
- `react-demo/`: direct React adapter example.
- `solid-demo/`: Solid adapter example.
- `vanilla-demo/`: framework-free usage example.
- `shared/`: shared content, styles, and React components used to keep the examples visually aligned.
- `assets/`: source media used to derive demo frames and preview video assets.

If you want one place to iterate on the public-facing experience, start with `pnpm dev:landing`, which runs the Next demo.
