# Docs

This directory stores the written references that back the example site.

- `getting-started/`: installation flow, quick starts, and runtime entry points.
- `api/`: package, config, and CLI reference notes.
- `architecture/`: engine, adapter, plugin, and frame-pipeline design notes.
- `guides/`: implementation guides such as custom scrollbars, performance tuning, manifest handling, and frame extraction.
- `examples/`: example-focused walkthroughs.
- `troubleshooting/`: common failure modes and recovery steps.

The Next demo exposes the same material through the docs route, while these files remain the source-controlled long-form references.
