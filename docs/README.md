# Docs

This directory stores written documentation that complements the example site.

- `getting-started/`: installation and framework quick starts.
- `api/`: package and config reference notes.
- `architecture/`: engine, adapter, plugin, and frame-pipeline design notes.
- `guides/`: implementation guides such as custom scrollbars, performance tuning, and manifest handling.
- `examples/`: example-focused walkthroughs.
- `troubleshooting/`: common failure modes and recovery steps.

The Next demo exposes the same content as a docs-style site, but these files remain the source-controlled long-form references.
