# React API

Main exports:

- `ImmersiveScroll`
- `ImmersiveCanvas`
- `ImmersiveLayer`
- `ImmersiveFloating`
- `ImmersiveScrollbar`
- `ImmersiveTriggerZone`
- `ImmersiveDebugPanel`
- hooks like `useImmersiveScroll`, `useImmersiveFrame`, and `useImmersiveProgress`

See `examples/react-demo` for a full-page composition using these exports.
