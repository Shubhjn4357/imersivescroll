# Packages

This directory contains the public package plus the internal implementation packages that back it.

- [`immersive-scroll/`](immersive-scroll/README.md): The primary public npm package.
- [`horizontal-scroll/`](horizontal-scroll/README.md): High-performance horizontal translation package.
- [`svg-mask/`](svg-mask/README.md): Cinematic SVG reveal and masking package.
- [`shared/`](shared/README.md): Internal shared types, validators, and utilities.
- [`core/`](core/README.md): Core platform-agnostic engine primitives.
- [`react/`](react/README.md): React adapter, hooks, and context.
- [`next/`](next/README.md): Next.js specific wrappers.
- [`solid/`](solid/README.md): SolidJS primitives.
- [`web/`](web/README.md): Vanilla JS and custom-element exports.
- [`cli/`](cli/README.md): Frame extraction and asset pipeline CLI.

The packages `immersive-scroll`, `@immersive-scroll/horizontal-scroll`, and `@immersive-scroll/svg-mask` are published to npm. The rest are internal workspace modules.
